# Робот для формирования отчётов в 1С (Кейс 5)

## Описание
Робот читает параметры отчёта из config.json, открывает веб-интерфейс 1С через браузер, авторизуется, переходит к оборотно-сальдовой ведомости, вводит параметры (период, организация), формирует отчёт и сохраняет результат.

## Установка и запуск
1. Распакуйте архив с проектом.
2. Откройте проект в Puzzle RPA Studio.
3. Заполните конфиг в папке `resource/`. Пример конфига:
```json
{
  "report_type": "osv",
  "period_start": "01.03.2025",
  "period_end": "31.03.2025",
  "organization": "Магазин №23",
  "output_path": "resource/output",
  "output_format": "xlsx",
  "file_name": "osv_march"
}
```
4. Запустите робота: откройте `process/main` и нажмите F5.

## Параметры config.json
| Поле | Описание |
|------|----------|
| report_type | Тип отчёта (osv) |
| period_start | Дата начала (ДД.ММ.ГГГГ) |
| period_end | Дата окончания (ДД.ММ.ГГГГ) |
| organization | Наименование организации как в 1С |
| output_path | Папка для сохранения |
| output_format | Формат файла (xlsx) |
| file_name | Имя файла без расширения |

## Результат
Файл отчёта в папке `resource/output/`.
